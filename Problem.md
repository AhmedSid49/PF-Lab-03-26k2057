# Problem Statements and Pseudocode

Problem 1 — Student Information

Pseudocode
1. Start
2. Declare a character array variable for the student's name.
3. Declare an int variable for the roll number.
4. Declare a floating-point (float) variable for the GPA.
5. Declare a character variable for the section.
6. Input the student's name.
7. Input the roll number.
8. Input the age.
9. Input the height.
10. Input the GPA.
11. Input the section character.
12. Display all the student information in an organized format.
13. End

Problem 2 — Character Input and Output

Pseudocode
1. Start
2. Declare a character variable.
3. Ask the user to enter a character.
4. Read the character using `getchar()`.
5. Display the character using `putchar()`.
6. End

Problem 3 — Floating-Point Precision

Pseudocode
1. Start
2. Declare a float variable.
3. Ask the user to enter a floating-point value.
4. Read the value.
5. Display the value using default precision.
6. Display the value with 2 digits after the decimal point.(%.2f)
7. Display the value with 4 digits after the decimal point.(%.4f)
8. Display the value with 6 digits after the decimal point.(%.6f)
9. End
