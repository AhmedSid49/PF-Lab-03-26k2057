Lab Title:Introduction to GitHub and C Language

Introduction

This lab introduces the basics of GitHub, Markdown, and the C programming language. It focuses on concepts such as variables, data types, input/output functions, format specifiers, escape sequences, and formatting.

Objectives

1. Create and manage a GitHub repository.
2. Learn basic GitHub branching and commit operations.
3. Create and merge a Pull Request.
4. Understand basic C data types and format specifiers.
5. Practice C input and output functions.
6. Use Markdown to document programming concepts.

C Topics Covered

- Variables
- Data Types
- Format Specifiers
- Input/Output Functions
- Escape Sequences
- Floating-Point Precision
- Character Input and Output
- String Input

> "Learning the fundamentals makes programming easier to understand."
